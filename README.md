# 🚀 Portafolio de Proyectos - Grupo 13

Este proyecto es un **"Lanzador de Aplicaciones"** (App Launcher) desarrollado en C# y Windows Forms. Su objetivo principal es servir como un portafolio interactivo que centraliza el acceso a todos los proyectos desarrollados durante el curso de **Estructura de Datos** en UPN.
